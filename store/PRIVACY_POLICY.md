# Browser Automation Runner — Privacy Policy

Status: Store preparation text. A public URL can be assigned later if the submission form requires one.

Browser Automation Runner is a Windows desktop application that performs deterministic browser steps configured by the user with Playwright and Chromium. It is not an AI agent and does not decide which websites to automate on its own.

Depending on the workflow, the app may process HTTPS URLs and allowed host names, page content required for configured browser actions, user-provided form values, environment-variable references for sensitive values, screenshots, downloads, workflow JSON, and local output paths.

Live browser execution connects to hosts permitted by the user's workflow. Dry Run is an offline configuration and allowlist validation step and does not perform live browser actions.

Workflow JSON, screenshots, downloads, and related files are stored locally in locations selected by the user and constrained by the configured root directory. Existing outputs are not overwritten unless the workflow explicitly allows replacement.

Websites visited by the user are governed by their own terms and privacy policies. Users are responsible for having permission to automate the selected website and account.
